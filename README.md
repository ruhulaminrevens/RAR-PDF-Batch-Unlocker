# RAR-PDF-Batch-Unlocker
Unlock PDF-এর মতো সুবিধা নিজের Windows PC-তে সম্পূর্ণ offline পাওয়া—বিশেষ করে শত শত (প্রায় 100–1,000) password-protected PDF bulk processing করার জন্য। ফাইলগুলো ব্যাংক স্টেটমেন্ট/ক্রেডিট কার্ড, অফিস/অ্যাকাউন্টিং/ফাইন্যান্স, ব্যক্তিগত/সরকারি ও অন্যান্য নথির মিশ্রণ। কিছু password জানা আছে, আবার কিছু ফাইল খুলতেই password চায় কিন্তু password জানা নেই।
