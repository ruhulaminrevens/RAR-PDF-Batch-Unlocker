# RAR PDF Batch Unlocker 1.1.0

A new dark workspace with consistent Windows branding, built on the existing offline qpdf engine.

- Navy/cyan/violet dashboard, persistent sidebar and scrollable settings.
- Password groups, folder mappings and optional Windows Credential Locker retained.
- Responsive scan, locked settings during a run, real progress/timing and safe stop.
- Searchable results, complete status filtering, CSV access and failed-only retry.
- Multi-size app icon across the GUI, taskbar, EXE, installer, shortcuts and uninstaller.
- Existing source/output isolation, stdin passwords and no-overwrite behavior retained.

**Validation:** See `docs/REDESIGN_VALIDATION.md` and the corresponding Windows Actions run. Release publishing is gated on the Windows tests, installer installation, real installed-GUI fixture processing and uninstall checks. SHA256SUMS.txt and VALIDATION.txt accompany the installer.

**Install:** Download `RAR-PDF-Batch-Unlocker-Setup.exe`, run it, then open the app from the Desktop or Start Menu. No separate Python or qpdf installation is required.

**বাংলায়:** Source ও Output আলাদা folder দিন → Scan / Analyze → জানা passwords add করুন → ছোট test batch চালিয়ে results ও CSV দেখুন। Originals অপরিবর্তিত থাকে; existing output overwrite হয় না।

The installer is unsigned. Strong unknown opening passwords cannot be bypassed. Keep unlocked documents in an access-controlled folder. v1.0.0 remains available unchanged.
