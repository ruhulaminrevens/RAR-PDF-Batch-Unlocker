# RAR PDF Batch Unlocker 1.2.0

Safer output, single-PDF selection, resume and faster batches — validated on Windows before release.

**Download:** `RAR-PDF-Batch-Unlocker-Setup.exe` below (Windows 10/11 x64). Installing over 1.1.0 upgrades in place; your PDFs and reports are not touched.

## What's new
- **Never a half-written output.** Each unlocked copy is written to a temporary file, checked with `qpdf --check`, then moved into place atomically and never over an existing file. A full disk or interruption leaves nothing that a later run could mistake for a finished file.
- **Damaged files are reported, not copied.** Empty, truncated or non-PDF files now show **Invalid PDF** instead of "already unencrypted".
- **Add single PDFs** (multi-select) with or without a source folder; duplicates are ignored.
- **Resume** an interrupted run, or **retry** only failed files, from a previous report.
- **Parallel workers** (1–16) and a **timeout** setting. On the CI machine 4 workers processed 1,000 PDFs in 51 s (about 2.4× faster than 1 worker).
- **Stop** ends the running qpdf step at once.
- **Clear statuses with a next step:** File locked, Access denied, Disk full, Path too long, Rebuild failed and Name conflict.
- **Reports:** a CSV protected against spreadsheet formula injection, a JSON run record and a readable HTML summary that includes the app and qpdf versions.
- **Results:** sortable columns, a “Needs attention” filter and per-file details with the full path and what to do.
- **Bangla and long paths** are handled, including folders over the classic Windows 260-character limit.
- **125–200 % display scaling:** clipping fixed and tested from 100 % to 200 %.
- Local diagnostics log with every session password redacted; the bundled engine is checked against a SHA-256 manifest at start-up; third-party notices are installed.

## Validation
Windows CI run [39057321337](https://github.com/ruhulaminrevens/RAR-PDF-Batch-Unlocker/actions/runs/39057321337) on commit `6c76f04`:
- 52 automated tests passed and 1 was skipped (a case-sensitivity test that cannot apply on Windows). They ran with real qpdf 12.4.2 and with long-path support turned off.
- Upgrade from the published v1.1.0 left exactly one Programs and Features entry.
- The installed app, driven with real mouse and keyboard input, processed 5 synthetic PDFs: 3 unlocked, 1 with no password match and 1 already unencrypted. Outputs were re-verified, originals were unchanged and no password appeared in the report.
- Uninstall left no files or shortcuts.
- The 100/1,000-PDF benchmark passed.

Details: [docs/validation/v1.2.0.md](https://github.com/ruhulaminrevens/RAR-PDF-Batch-Unlocker/blob/release/v1.2.0/docs/validation/v1.2.0.md).

## Known limits
- The installer is unsigned, so Windows SmartScreen may warn. Compare the SHA-256 in `SHA256SUMS.txt`.
- Strong unknown opening passwords cannot be bypassed. Only your supplied passwords are tried.
- Drag-and-drop is not included yet.
- Display scaling was tested through Tk DPI emulation in CI; please confirm on your own screen.
- An Android version is not available yet.
