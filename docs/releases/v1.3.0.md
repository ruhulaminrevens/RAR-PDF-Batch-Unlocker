# RAR PDF Batch Unlocker 1.3.0

A new **PDF tools** section alongside the batch unlocker — all offline, validated on Windows before release.

**Download:** `RAR-PDF-Batch-Unlocker-Setup.exe` below (Windows 10/11 x64). Installing over 1.1.0 or 1.2.0 upgrades in place; your PDFs and reports are not touched.

## New: PDF tools
- **Merge PDFs** — combine several PDFs into one, in the order you choose.
- **Split & organize** — split every page into its own file, or keep, reorder and rotate selected pages (`1,3-5,8`).
- **Images → PDF** — combine jpg, png, bmp, tiff or webp images into one PDF.
- **PDF → images** — save each page as png, jpg, tiff or webp at 72–300 DPI (keeps the exact layout, good for printing).
- **PDF → Word / Excel (draft)** — text-based export for PDFs with selectable text. Scanned (image-only) PDFs need OCR, which is not included, so they come out empty — use **PDF → images** for those.

All tools run on your PC, nothing is uploaded. Output is verified and written atomically, existing files are never overwritten, and a protected input asks for its open password (which never reaches any log or report).

## Everything from 1.2.0 is still here
Safe atomic unlocking, resume and retry, parallel workers, clear statuses, CSV/JSON/HTML reports, Bangla and long-path support.

## Licensing and limits
- Rendering uses **pypdfium2** (BSD/Apache) and extraction uses **pdfplumber** (MIT). PyMuPDF (AGPL) is deliberately not used; see `THIRD-PARTY-NOTICES.txt`.
- The installer is unsigned, so Windows SmartScreen may warn. Compare the SHA-256 in `SHA256SUMS.txt`.
- Word/Excel export is a text draft, not an exact-layout conversion. Drag-and-drop and OCR are not included.
- Display scaling was tested through Tk DPI emulation in CI; please confirm on your own screen.
- An Android version is not available yet.
