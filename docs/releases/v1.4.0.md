# RAR PDF Batch Unlocker v1.4.0

A new PySide6/Qt desktop interface for the existing offline qpdf engine.

## What's changed
- Dark workspace with persistent sidebar navigation: Workspace, Passwords, Results, PDF tools, Run settings and Help.
- Drag-and-drop inputs, password groups, result filtering, retry/resume settings and the existing offline PDF tools.
- Asynchronous Qt workers keep processing off the GUI thread; the Windows deadlock regression is covered by a dedicated test.
- Corrected the legacy Tk drag-drop test fixture: both Windows paths are Tcl-braced so backslashes remain literal. Application processing code was unchanged by this fix.

## Install · বাংলায়
Download **RAR-PDF-Batch-Unlocker-Setup.exe**, run it, then open the app from Desktop or Start Menu. No separate Python or qpdf installation is required.

নতুন Qt dark interface-এ Source/Add PDFs → আলাদা Output folder → জানা Passwords → Unlock batch ব্যবহার করুন। প্রথমে ছোট test batch চালিয়ে result দেখুন।

## Limits
- Windows 10/11 x64; the installer is unsigned.
- Only supplied passwords are tried; unknown strong opening passwords cannot be bypassed.
- PDF → Word/Excel remains a text draft; scanned PDFs require OCR, which is not included.
- Qt functional scenarios run offscreen against source; installed-EXE validation checks startup and rendering, rather than a complete click-through processing session.
- Physical display scaling, antivirus behaviour and user PDFs still require checks on real PCs.
